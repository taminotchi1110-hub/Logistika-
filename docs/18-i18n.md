# 18. Koʻp tillilik — oʻzbek, rus, ingliz

> Holat: 9-bosqich · mobil ilova va server bildirishnomalari toʻliq uch tilda.
> Admin panel hozircha faqat oʻzbekcha (ichki xodimlar uchun).

## 18.1 Asosiy qoidalar

1. **Til ilova ichida tanlanadi.** Tizim tili faqat boshlangʻich qiymat:
   Oʻzbekistonda telefon ruscha, foydalanuvchi esa oʻzbekcha oʻqishi keng
   tarqalgan holat. Tanlov `SharedPreferences` da saqlanadi.
2. **Server tilni `users.lang` dan biladi.** Ilova uni interfeys tiliga
   moslab turadi (`PATCH /me {lang}`), har bir soʻrovda `Accept-Language`
   yuboradi, OTP soʻrovida esa `lang` (foydalanuvchi hali kirmagan).
3. **Server tayyor matn yubormaydi — maʼno yuboradi.** Moslik sabablari —
   kod (`NEAR_PICKUP:12`), buyurtma holati — kod (`LOADED`); matnni ilova
   joriy tilda yigʻadi. Server matni (`statusLabel`) faqat zaxira: ilova
   tanimaydigan yangi holat chiqsa koʻrsatiladi.
4. **Bildirishnomalar — shablonlar.** Servis `tpl(kalit, parametrlar)`
   beradi, matn qabul qiluvchining tilida yigʻiladi (18.3).

## 18.2 Mobil ilova

| Nima | Qayerda |
|---|---|
| Tarjimalar | `apps/mobile/lib/l10n/app_uz.arb` (shablon, `@` izohlar bilan), `app_ru.arb`, `app_en.arb` |
| Yigʻish | `flutter gen-l10n` (`flutter pub get` ham yigʻadi) → `lib/l10n/app_localizations*.dart` (gitda yoʻq) |
| Til tanlovi | `core/l10n/locale_controller.dart` — `AppLocale`, `localeControllerProvider` |
| Serverga yetkazish | `features/profile/presentation/language_sync.dart` |
| Formatlash | `core/l10n/formatters.dart` — `context.l10n`, `context.soum()`, `context.weight()`, `context.distance()`, `context.language` |

**Ekranda:** `context.l10n.kalit`. Pul va birliklar faqat `context.soum(...)`
orqali — `formatSoum(...)` toʻgʻridan-toʻgʻri chaqirilsa oʻsha joyda
oʻzbekcha "soʻm" qolib ketadi.

**Domen tilni bilmaydi.** `OrderStatus`, `LoadStatus`, `DocumentType` va
boshqa enumlar API bilan ishlaydi; yorliqlar `presentation/*_l10n.dart`
kengaytmalarida: `status.localized(l10n)`, `status.action(l10n)`.

**Spravochnik nomlari** (viloyat, transport turi, kategoriya) serverdan uch
tilda keladi: `name.of(context.language)`. `name.uz` ni qotib yozish —
xato (ruscha interfeysda oʻzbekcha nom chiqadi).

**Ruscha koʻplik** — ICU `plural`:

```json
"agoMinutes": "{count, plural, one{{count} минуту} few{{count} минуты} many{{count} минут} other{{count} минуты}}"
```

**Sana tartibi tilga bogʻliq** ("9 sentabr" / "September 9"), shuning uchun
tarjimada oy nomi emas, BUTUN QOLIP turadi: `dateTimeFull`, `dayMonth`.
Ruscha oy nomlari qaratqich kelishigida (`monthsFull`: "сентября").

**Testlar.** `test/helpers/localized_app.dart`:

```dart
await tester.pumpWidget(localizedApp(locale: AppLocale.ru, home: const MyScreen()));
```

Har bir ekran uchun kamida bitta ruscha test yoziladi — tarjima kaliti
unutilgan joyni aynan shu ushlaydi. `l10n-untranslated.json` doim `{}`
boʻlishi shart.

## 18.3 Backend

**Bildirishnomalar:** `apps/api/src/modules/notifications/notification-templates.ts`.

```ts
await this.notifications.notify({
  userId,
  type: 'offer.accepted',
  template: tpl('offer.accepted', {}),
  deepLink: `karvon://order/${orderId}`,
});
```

`NotificationsService.notify` qabul qiluvchining `users.lang` ini oʻqib
matnni yigʻadi. `notifyBoth` da har bir tomon OʻZ tilida oladi. Chat xabari
(yuboruvchi ismi + matnning oʻzi) tarjima qilinmaydi — u `title`/`body`
bilan beriladi; tur tizimi ikkalasidan faqat bittasini qabul qiladi.

**Yangi bildirishnoma qoʻshish:**

1. `TEMPLATES` ga uchala tilda yozing.
2. `notification-templates.spec.ts` dagi `SAMPLES` ga namuna qoʻshing —
   yozilmasa kompilyatsiya xatosi (mapped type). Test boʻsh matn,
   `undefined` va tarjima qilinmagan sarlavhani ushlaydi.
3. Servisda `template: tpl('kalit', {...})`.

**Pul formati:** `formatMoney(tiyin, lang)` → "240 000 soʻm" / "240 000 сум" /
"240 000 UZS".

**Xato matnlari** serverda oʻzbekcha qoladi — ilova ularni KOD boʻyicha
tarjima qiladi (`apps/mobile/lib/core/api/api_exception.dart`).
`test/core/api/localize_error_test.dart` backend `error-codes.ts` dagi har
bir kod ilovada tarjimaga ega ekanini tekshiradi.

## 18.4 Yangi til qoʻshish (masalan, qozoqcha)

1. **DB:** `users.lang` ruxsat etilgan qiymatlari va spravochnik
   jadvallariga `name_kk` ustuni — migratsiya.
2. **Backend:** `LangCode` turiga `'kk'`. Shundan keyin kompilyator
   `STATUS_LABEL`, `DOCUMENT_LABEL` va har bir shablonda yetishmayotgan
   tilni koʻrsatadi (`Record<LangCode, ...>`).
3. **Mobil:** `AppLocale` ga `kk`, `app_kk.arb`, `LocalizedName` ga `kk`.
4. Tarjimondan keyin: `flutter gen-l10n` → `l10n-untranslated.json`
   boʻshligini tekshiring.

## 18.5 Tarjimon uchun eslatma

- Oʻzbek lotin yozuvida **ʻ** (U+02BB, "oʻ", "gʻ") va **ʼ** (U+02BC,
  tutuq belgisi) ishlatiladi — oddiy apostrof (') emas.
- `{placeholder}` larni tarjima qilmang va oʻchirmang.
- `@kalit` dagi `description` — matn qayerda va nega shunday
  ekanini tushuntiradi (masalan tugma matni holat nomi emas, buyruq
  shaklida: holat "Yuk ortildi", tugma "Yukni ortdim").
